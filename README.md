# Заполнение ценового среза через Claude Code (без отдельного API)

Фото ценников читает **сам Claude Code** на вашей подписке Claude (Pro или Max),
а небольшой скрипт `excel_tools.py` заполняет таблицу. Отдельный платный
API-ключ НЕ нужен.

Что делает система: вы кладёте фото ценников в папки по сетям → говорите Claude
Code «обработай фото за такую-то дату» → он распознаёт продукт/производителя/
массу/цену, находит нужную строку и проставляет цену в **новый столбец-дату**
прямо в `таблица.xlsx` — отдельных копий не создаётся, вся история дат хранится
в одном файле. Спорные позиции он перечисляет «на проверку».

---

## Установка (один раз)

### 1. Claude Code на подписке Pro/Max
Нужна активная подписка Claude (Pro или Max) — этого достаточно, **API-ключ не
требуется**. Установка и вход — по официальной инструкции:
https://docs.claude.com/en/docs/claude-code

При входе авторизуйтесь своей учётной записью Claude (Pro/Max).

> **Важно.** Если на компьютере выставлена переменная окружения
> `ANTHROPIC_API_KEY`, Claude Code начнёт списывать деньги по API в обход
> подписки. Убедитесь, что она НЕ задана. Текущий режим показывает команда
> `/status` внутри Claude Code.

### 2. Python (для excel_tools.py)
https://www.python.org/downloads/ — при установке галочка «Add Python to PATH».
Затем в папке проекта: `pip install -r requirements.txt`
(Claude Code может сделать это сам по вашей просьбе.)

### 3. Папка проекта
```
price_filler\
   excel_tools.py
   CLAUDE.md
   requirements.txt
   таблица.xlsx
   фото\
      Пятерочка\  Магнит супермаркет\  Магнит моя цена\
      Лента супермаркет\  Лента гипермаркет\  Монетка\
      Мария-ра\  Ашан\  Окей\  Быстроном\  Ярче\  Чижик\
```
`CLAUDE.md` лежит в корне специально — Claude Code читает его автоматически и по
нему знает весь порядок работы и правила.

---

## Как пользоваться каждый раз
1. Разложите свежие фото по папкам сетей (по одному ценнику на фото).
2. Откройте папку проекта в Claude Code.
3. Напишите, например: **«Обработай фото за 05.03.2026»**.
   Claude Code сам пройдёт по папкам, прочитает ценники, проставит цены и в конце
   покажет, что ушло «на проверку».
4. Сверьте «на проверку» и при необходимости допишите цены руками прямо в
   `таблица.xlsx` — это один и тот же файл на все даты, ничего переименовывать
   не нужно.

## Про объём и лимиты (важно и честно)
Интерактивный Claude Code расходует **ту же квоту, что и обычный чат Claude**, с
откатом примерно раз в 5 часов и недельным потолком. 800–1000 фото за раз — это
много, и на плане Pro вы, скорее всего, упрётесь в лимит окна. Практичные
варианты:
- обрабатывать **по сетям/частями** в течение дня (окно восстанавливается ~каждые
  5 часов);
- использовать план **Max** — там запас заметно больше.

Способ без потолков — это как раз отдельный API (платится за объём), от которого
вы отказались. Если когда-нибудь объёмы перерастут подписку, к нему можно
вернуться; пока идём через подписку.

## Настройка
- Соответствие «папка → сеть» и правила цены зашиты в `excel_tools.py`
  (словарь `FOLDER_TO_CHAIN`) и в `CLAUDE.md`. Новую сеть добавляют в оба места.
- Правило цены: при двух ценах — крупная (по карте/акции); при «от 1/2/3 шт» —
  «от 1 шт».
- Фото с iPhone (.HEIC) лучше заранее перевести в JPG.

## Идея на будущее
На каждом ценнике есть штрихкод. Если завести в таблице столбец штрихкодов,
совпадения можно будет запоминать и со следующего месяца сопоставлять мгновенно
и без ошибок.
